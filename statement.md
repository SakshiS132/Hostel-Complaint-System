Hostel Complaint Management System

 Problem Statement
Hostel students face issues like water leakage, electricity problems, and room maintenance. There is no proper system to register and track complaints.

 Why This Matters
Without a system, complaints get ignored. This project helps manage complaints efficiently.

 Approach
The system allows students to:
- Register
- Submit complaints
- View complaint status

Admin can manage complaints.

 Tech Stack
- Java
- OOP Concepts
- File handling

 Features
- Student login
- Submit complaint
- View complaints
- Complaint tracking

 Challenges Faced
- Managing file storage
- Designing class structure
- Handling user input
