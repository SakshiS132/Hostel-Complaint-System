# Hostel Complaint Management System

A Java-based Hostel Complaint Management System to register, track, and manage student complaints.

## Problem Statement
In hostels, students often face issues such as water leakage, electricity failure, WiFi problems, and cleanliness issues. Managing these complaints manually can be confusing and inefficient. This project provides a simple digital solution to record and manage complaints.

## Features
- Add complaint with student details
- View all complaints
- Update complaint status
- Menu-driven console program
- Automatic complaint status set to Pending at first

## Technologies Used
- Java
- ArrayList
- Scanner
- Object-Oriented Programming

## Project Structure
- `Main.java` - main menu and program flow
- `Student.java` - stores student details
- `Complaint.java` - stores complaint details and status

2. Compile the files:
